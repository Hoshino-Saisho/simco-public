聊天记录网页

——

包含英文交易，航天交易，中文游戏，中文交易和中文社交等频道记录

用户可自行选择日期，频道和领域

也可自行搜索关键词或者玩家

显示头像，发送时间，领域，证书数量，以及其他状态

无法记录并显示已删除的信息，但如果在删除前记录则不会影响


——


中文社交与中文游戏频道有ai总结功能

其中只有社交是全程ai总结，无任何人工干预

而游戏频道因为信息过多，会采取人工筛选加学习模拟程序辅助

用户可以标记那些筛选进ai的信息

simco-chat-stats.user.js是网页油猴插件

手机版需要firefox浏览器然后下载油猴
